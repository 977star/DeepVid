# DeepVid · 知影

把音视频转化为可阅读、可检索、可复用的图文笔记。

知影支持图文精读、章节速读、思维导图与阅读追问，并可通过 MCP 连接 AI 助手、导出至 Obsidian。支持在线模型与本地模型，以及本地离线语音识别。

**[前往官网查看完整功能介绍与使用指南 →](https://deepvid.977star.com)**
