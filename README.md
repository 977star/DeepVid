# DeepVid · 知影

把音视频转化为可阅读、可检索、可复用的图文笔记。

Turn audio and video into illustrated notes you can read, search, and reuse.

支持图文精读、章节速读、思维导图与阅读追问，通过 MCP 连接 AI 助手、导出至 Obsidian；支持在线与本地模型，以及离线语音识别。

Illustrated deep reading, chapter overviews, mindmaps, and contextual Q&A, with MCP integration and Obsidian export. Supports online and local models, plus offline speech recognition.
